Every published test

This page lists every automated test result we publish. Each row is one test that ran on its own. Results are never added up into a single score.

How to read a result

  • Passed met every required rule.
  • Failed missed at least one required rule.
  • Needs attention finished, but something should be reviewed by a person.
  • Couldn't finish the test itself broke, so there is no verdict.

Words you will see

  • Criteria are the written rules each finished task is graded against.
  • A blocker is a rule that must pass. Missing one means Failed. Missing a non-blocker means Needs attention.
  • Could not be judged means the grader could not decide whether a rule was met. It never counts as a pass.
  • Regression comparison checks the skill against its previous version. Until that comparison runs, even a perfect score stays at Needs attention.
  • Thresholds are the minimum scores the skill must reach overall.

See the test opens exactly what was checked. Signed record opens the tamper-evident proof of the result.

Last updated: Nov 3, 2026. Some projects may be newer; each row shows its own test date.
