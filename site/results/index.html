Pass means the tested requirements were met. Fail means a requirement was missed. Advisory needs attention; error means a check could not finish. No data means no verified result is available. None of these is a blanket approval of a system.

Each record uses a versioned definition and a verified signed evidence bundle. Counts stay within one kind of test, never a blended score across different tests. How to read the technical evidence.
